# A-T04-T17 Task Report

## WHAT

- Added `scripts/fetch_eurlex.py`. It restricts fetches to EUR-Lex, records the fetched-document SHA-256 and retrieval timestamp, parses article sections, and can stage source text into the rule file. It deliberately **never** marks a rule `human_verified`; an explicit human review is required.
- Added `backend/app/stages/s2_extract_fields.py` with deterministic text/HTML extraction, original-input character offsets, exact quote anchoring, and an optional OpenAI-compatible Token Factory/Nemotron Nano JSON-Schema call. A missing `MODEL_NANO` or `NEBIUS_API_KEY` means no model call. Model absences do not override deterministic results; unsupported or mismatched model quotes are downgraded to `UNPARSEABLE`.
- Added `POST /v1/listings/screen` to `backend/app/main.py`. It returns ListingFields, a Verdict-shaped object, and Citation-shaped citation chips. Unverified statutory rules cause `UNDETERMINED`.
- Added `backend/tests/test_extraction.py`, including synthetic text/HTML and schema-conformance tests, model-failure and fabricated-quote tests, and a synthetic-only test demonstrating a blocking missing-responsible-person result once rules are treated as verified.
